Start a new ICP qualification run.

Invoke the `icp-qualify` skill and follow it from **Step 1 — Capture the
campaign**. Ask the intake questions in a single message and wait for the
user's answers before doing anything else.

Do not create folders, inspect files, or run any script until the campaign
brief has been captured -- except `python scripts/typesafe_judge.py --status`,
which is read-only and shapes the wording of the judge question.
